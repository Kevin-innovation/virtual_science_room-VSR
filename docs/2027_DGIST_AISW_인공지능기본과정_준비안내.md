## VSR이란

> [!abstract] 이름
> **VSR**은 **Virtual Science Room**의 줄임말입니다. 한국어로는 **가상 과학실**입니다. 초등학교 과학실을 화면 속 3D 방으로 옮겨, 실험 기구를 조작하며 같은 실험을 여러 번, 조건을 바꿔 가며 해보는 웹 사이트입니다. 가칭이며 이 집의 포트폴리오 주제입니다. 담당은 **DLAB Kevin 선생님**입니다.

#VSR #가상과학실

### 한 줄로 말하면

학교 과학실에서는 추나 경사면을 수업 시간에 한 번만 만져 보고 끝나는 일이 많습니다. 시간이 없고, 재료가 모자라고, 위험한 조작은 선생님이 보여 주기만 하기도 합니다.

VSR은 그 과학실을 **웹 브라우저 안의 방**으로 만든 것입니다. 학생은 마우스로 방을 보고, 버튼과 슬라이더로 조건을 바꾼 뒤, 결과가 어떻게 달라지는지 스스로 셉니다.

제출하는 것은 사이트 주소가 아닙니다. 무엇을 궁금해서, 무엇을 바꾸고, 무엇을 재고, 무엇이 실패했는지를 담은 **A4 5쪽 PDF**입니다.

### 정식 소개

| 항목 | 내용 |
|:---|:---|
| 가칭 | VSR. 가상 과학실 |
| 무엇 | 초등 실험을 3D로 조작 |
| 실행 | 브라우저에서 엽니다 |
| 실험자 | 초6 학생 |
| 제작 | Kevin 선생님이 이끔 |
| 학생 역할 | 질문·측정·설명 |
| 도구 | Three.js. 3D를 움직이는 도구 |
| 범위 | 실험 1개만 깊게 |
| 제출 | 탐구 과정 A4 5쪽 PDF |
| 아닌 것 | 수료증, 게임, 공식집이 아님 |

> [!info] Three.js는 한 문장입니다
> 종이에 그린 과학실을 화면에서 돌리고 떨어뜨리고 기울이게 해 주는 도구입니다. 자소서에는 WebGL, 렌더링, 엔진 같은 말을 쓰지 않습니다.

### 왜 가상 과학실인가

실제 과학실은 없어지면 안 됩니다. VSR은 과학실을 대신하는 것이 아니라, 과학실에서 못다 한 반복과 비교를 가능하게 하는 방입니다.

| 학교 과학실 | VSR |
|:---|:---|
| 끝나면 기구를 치움 | 집에서도 다시 누름 |
| 조건 반복이 어려움 | 슬라이더로 바로 바꿈 |
| 실패하면 재료가 없음 | 처음부터 다시 시작 |
| 위험 조작은 시연만 | 안전한 범위에서 조작 |
| 측정표를 급히 씀 | 멈추고 천천히 셈 |
| 한 반이 함께 봄 | 혼자 한 뒤 맡길 수 있음 |

가상 실험이 실제와 다르게 움직이면 그 차이를 숨기지 않습니다. 컴퓨터가 틀린 과학을 보여 줄 수 있다는 점이 인공지능 기본과정의 판단 기준·윤리와 맞습니다.

### 학생이 VSR에서 하는 일

1. 과학실에서 아쉬웠던 실험을 고릅니다.
2. 바꿀 것 1개와 잴 것 1개를 정합니다.
3. 종이로 방·기구·버튼을 스케치합니다.
4. Kevin 선생님과 함께 화면에서 움직이게 만듭니다.
5. 값을 작게, 중간, 크게 바꿔 3번 이상 셉니다.
6. 교과서·손 실험과 다른 점을 찾습니다.
7. 이상한 일이 나오면 실패로 적고 고칩니다.
8. 친구나 가족에게 버튼을 맡겨 설명이 통하는지 봅니다.

> [!example] 초6이 입으로 말하는 VSR
> “컴퓨터 안에 과학실을 만들었어요. 추를 매달고 실을 길게 하면 흔들림이 느려지는지 세어 봤어요. 처음엔 공이 바닥 밑으로 빠져서, 바닥을 벽으로 고쳤어요. 코드는 Kevin 선생님이 도와주셨고, 무엇을 바꾸고 셀지는 제가 정했어요.”

### 실험은 하나부터

접수 전까지 **실험 1개**가 끝까지 움직이면 됩니다. 나머지는 5쪽에 “다음에 넣고 싶은 실험”만 적습니다.

**추천 1. 추의 흔들림**
바꿀 것: 실 길이. 잴 것: 흔들린 느낌 또는 횟수.

**추천 2. 경사면과 공**
바꿀 것: 기울기. 잴 것: 도착하는 데 걸린 느낌.

**추천 3. 자석과 클립**
바꿀 것: 거리. 잴 것: 붙는지 안 붙는지.

**가능. 전구와 전선**
바꿀 것: 연결. 잴 것: 켜짐 꺼짐.

**가능. 손전등과 그림자**
바꿀 것: 위치. 잴 것: 그림자 길이.

공식으로 자랑하지 않습니다. “길수록 느려 보였다”처럼 눈으로 본 말을 씁니다.

### 인공지능 기본과정과 이어지는 점

코딩 문법보다 데이터, 정답, 판단 기준, 분류, 틀린 설명을 체험으로 봅니다.

| 기본과정 | VSR에서 하는 것 |
|:---|:---|
| 데이터 | 길이·기울기·횟수 관찰 |
| 정답 비교 | 예상과 화면이 같았는지 |
| 판단 기준 | 버튼을 어디까지 밀지 |
| 분류 | 붙음과 안 붙음 |
| 모델이 틀림 | 가상이 실제와 다름 |
| AI 윤리 | 가상만 믿어도 되는지 |

챗봇을 억지로 넣지 않습니다. 넣은 경우에만 AI 설명과 내가 본 화면이 다른지를 5쪽에 적습니다.

### 무엇이 VSR이 아닌가

> [!warning] 이렇게 소개하지 마십시오
> Three.js로 엔진을 구축했다, 초등 과학 전 과정을 구현했다, 실제 과학실 대신 이 사이트만 하면 된다, 상장과 학원 진도를 섞었다. VSR은 **한 가지 실험을 끝까지 만져 본 가상 과학실**입니다.

### 면접용 정의 세 문장

1. VSR은 컴퓨터 안에 만든 초등학교 과학실입니다.
2. 저는 그곳에서 조건을 바꾸고 결과를 세어 보았습니다.
3. 화면이 실제와 다를 수 있어서 비교합니다. 만들 때는 Kevin 선생님이 도와주셨고, 질문과 측정은 제가 했습니다.
